500 emails/day

Sends directly through Gmail API, bypassing the 100/day Apps Script cap.

🔀

Mail merge tags

Use {{Name}}, {{Company}}, {{Role}} to personalise each email from your sheet columns.

🔄

Auto-resume

Writes send status per row. If a run times out, the next run skips already-sent rows.

📎

HTML emails

Compose rich HTML body with links, formatting, and Drive file links — no plain text only.

How it works

1

Paste the code into Apps Script

Open your sheet → Extensions → Apps Script. Paste appsscript.json and SendEngine.gs from the GitHub repo.

2

Connect your Google Cloud project

Create a GCP project, enable Gmail API, and attach the project number in Apps Script → Project Settings.

3

Format your sheet

Columns: Name | Designation | Company | Recipient (email) | Merge status | Note. Row 1 is the header.

4

Run dryRun() first, then sendAll()

dryRun() previews the first 3 merged emails in logs. When satisfied, run sendAll() — it self-schedules past the 6-minute limit.
